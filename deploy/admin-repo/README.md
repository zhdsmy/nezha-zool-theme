# Nezha ZOOL Admin

This repository distributes the ZOOL management dashboard for Nezha v2.6+. Source code and the public status page are in [nezha-zool-theme](https://github.com/zhdsmy/nezha-zool-theme).

Open **Settings → Frontends**, select **Admin frontend**, and enter `https://github.com/zhdsmy/nezha-zool-admin`. Choose **Read releases**, install the tag matching your public frontend, and select **Activate**. Open `/dashboard/` to check the result.
